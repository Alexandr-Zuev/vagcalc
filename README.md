# Калькулятор конфигурации железнодорожных весовых платформ

## Суть
Инструмент для инженеров и проектировщиков весового оборудования, который прямо в браузере подбирает оптимальную геометрию платформенных весов под конкретный тип вагона с учётом всех нормативных ограничений. Работает полностью на клиенте — без сервера и базы данных.

## Какую проблему решает
Проектирование весовой платформы для взвешивания вагонов требует учёта противоречивых требований:
- Слишком короткая платформа — не все оси вагона стоят на весах, растёт погрешность измерения
- Слишком длинная платформа — соседний вагон, сцепленный с взвешиваемым, заезжает на весы и искажает показания
- Неправильный зазор между секциями — попадает на жёсткую базу тележки, что влияет на точность

Вручную перебирать варианты долго, калькулятор делает это мгновенно.

## Что умеет
✅ Автоматический расчёт допустимого диапазона длин платформы для заданного вагона  
✅ Подбор конфигурации: односекционная или двухсекционная с зазором  
✅ Проверка нормативов: все оси на платформе, зазоры вне зоны тележек, безопасный запас до соседнего вагона  
✅ Альтернативные варианты с оценкой рисков  
✅ Наглядная SVG-схема с размерами, подписями и цветовой индикацией рисков  
✅ Библиотека пресетов типовых вагонов (крытые, зерновозы, цистерны, полувагоны)  
✅ Три статуса результата: готово к использованию / требует осторожности / невозможно  
✅ Работа офлайн — вся логика в браузере, сеть не нужна после загрузки  

## Техническая реализация
Чистый фронтенд (React + Vite + TypeScript + Tailwind CSS):

- [src/utils/geometry.ts](./src/utils/geometry.ts) — геометрия вагона и платформы: оси, секции, проверка попадания осей и тележек сцепленного вагона
- [src/utils/solver.ts](./src/utils/solver.ts) — перебор конфигураций, ограничения по длине, ранжирование кандидатов
- [src/utils/format.ts](./src/utils/format.ts) — форматирование размеров
- [src/data/presets.ts](./src/data/presets.ts) — пресеты типовых вагонов (константы)
- [src/components/](./src/components/) — форма ввода, карточки результатов, SVG-схема

Состояние — в React useState, никакого сервера, портов и прокси

## Три статуса результата

| Статус | Значение |
|---|---|
| Готово к применению | все оси на секциях, тележки соседей не задеты, запас ≥ m |
| Требует осторожности | геометрия корректна, но фактический запас меньше требуемого m |
| Решения нет | нарушены геометрические ограничения: оси вне секций или тележка соседнего вагона на платформе |

## Плюсы архитектуры
- Развёртывание — статические файлы на любой хостинг (GitHub Pages, Netlify, Vercel)
- Мгновенный отклик — расчёты без сетевых задержек
- Работает без интернета и в закрытых сетях
- Нет уязвимостей серверной части, нет нагрузки на инфраструктуру

## Установка и запуск

1. Установите зависимости:
```bash
npm install
```

2. Запустите в режиме разработки:
```bash
npm run dev
```

3. Соберите проект (с проверкой типов):
```bash
npm run build
```

4. Запустите тесты геометрии и подбора:
```bash
npm test
```

## Использование
1. Выберите тип вагона из пресетов или введите параметры вручную
2. Нажмите "Рассчитать конфигурацию платформы"
3. Выберите подходящий вариант из предложенных
4. Ознакомьтесь с визуализацией и характеристиками выбранной конфигурации
